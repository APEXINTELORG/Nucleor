# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of
conduct. The full text is available at:

  https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, be welcoming to newcomers, focus discussion on the
work, and assume good faith. Personal attacks, harassment, and discriminatory
language are not acceptable.

## Reporting

If you experience or witness behavior that violates this code, please open a
private report by email to the maintainer (see the GitHub profile for the
current address) or open a confidential issue at
https://github.com/APEXINTELORG/Nucleor/issues.

Reports will be reviewed promptly and confidentially. The maintainer reserves
the right to take any action necessary to maintain a productive community,
including warning, suspending, or banning offending contributors.
