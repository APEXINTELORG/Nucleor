# Lane 6 Report — Runtime ABI + RT Enforcement + Effects Wiring

**Branch:** `fix/audit-lane-6-runtime-abi-rt-2026-05-08`
**Worktree:** `worktrees/audit_fix_lane_6`
**Date:** 2026-05-08

## Summary

Closes the audit Lane 6 cluster: 3 Critical (Layer 7 manifest gaps,
F-NUM-002 SI cross-dim, F-NUM-003 bit-shift UB), the 17 Highs in
scope, plus several Mediums best-effort. RFC-0001 §3.2.4
deadline-enforcement promise is downgraded per option (b) of the
brief — v1.0 ships best-effort post-hoc detection only; mid-execution
HW-timer trap is deferred to v1.1+.

The ten missing manifest rows are now generated by
`tools/gen_helper_manifest.nr` (manual_extras list); the manifest
total goes from 875 to **886** with 0 REVIEW REQUIRED. VectorOps
pure-read members (`vec_get`, `vec_len`, `vec_pop`, `vec_set`,
`vec_is_empty`, `vec_last`, `vec_index_of_i64`) drop the bogus
`["alloc"]` class default; `vec_free` and friends correctly carry
`alloc_capability_or_arena_owned` (was `bounds_within_len`).

## Lane coordination notes

- **Lane 1 (`__nucleor_panic_div_u64` / `_rem_u64`):** Lane 6 did
  not add or modify these helpers. No collision expected. If Lane 1
  adds them, the manifest generator will pick them up automatically
  via the IR-declares path (no manual_extras entry needed) provided
  the s1 compiler's `get_rt_name` table is updated.
- **Lane 2 (effects framework gate):** Lane 6 ships the
  runtime-ABI-side wiring only — manifest correctness, manual_extras
  for ten previously-invisible public symbols, effects + proof
  obligation accuracy across the VectorOps and Concurrency classes.
  The actual effect-gate plumbing in the type checker remains
  Lane 2's responsibility.
- **Lane 5 (`direct_ffi` enforcement upgrade):** No overlap in this
  ship.
