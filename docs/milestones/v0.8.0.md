# v0.8.0 Milestone Tracker

**Target:** 2028-Q1
**Theme:** Stabilization, ABI freeze, safety-cert pilot
**Status (2026-04-24):** Planning

## Theme

v0.8.0 is the **stabilization** milestone. The language and
stdlib have been growing through v0.2-v0.7; v0.8 is the freeze:
no new features, only bug fixes, and a public commitment to
backward compatibility from this point forward.

After v0.8 ships, the path to v1.0 is one or two more cycles
of audit + ABI signing.

## Cross-cutting workstreams

### ABI freeze

- [ ] Stable C ABI for every `__nucleor_*` runtime symbol
- [ ] Versioned symbol table; old binaries find new runtimes
      via versioned `__nucleor_v1_*` aliases
- [ ] `nuc abi diff` reports any ABI-relevant change between
      two builds; CI gate fails on accidental break
- [ ] Public ABI documentation page

### Safety-cert pilot

Take one real safety-critical project (UAV flight controller,
robot-arm safety supervisor, medical infusion pump) all the
way through `nuc build --profile=cert` (introduced v0.7) and
produce the IEC 61508 / ISO 26262 certification artifact bundle:

- [ ] Architecture description (auto-generated from RFC chain)
- [ ] Hazard analysis tied to specific `#[require]` / `#[ensure]`
      contracts
- [ ] WCET evidence per safety-classified fn (RFC-0009)
- [ ] Test coverage report tied to MC/DC criterion
- [ ] Build provenance + signed binary

### Documentation completeness

- [ ] Every public API has a doc-comment
- [ ] `nuc doc` emits ready-to-publish HTML for all rods
- [ ] Tutorial series: 0-to-shipping-real-robot in 8 lessons
- [ ] "Migrating from C++ to Nucleor" guide
- [ ] "Migrating from Rust to Nucleor" guide

### Tooling polish

- [ ] LSP server full feature parity with rust-analyzer
  (completion, go-to-definition, find-references, rename,
  format, code-actions)
- [ ] Debug-adapter protocol implementation for VS Code /
      nvim-dap
- [ ] Coverage tool integrated with `nuc test`
- [ ] Profiler integrated with `nuc bench`

### Performance

- [ ] Self-host compile in < 1 s on the v0.2 baseline machine
      (target 5×+ improvement over v0.7)
- [ ] Stdlib operations match `-O3 C` within 5% on
      benchmark suite
- [ ] Generated binaries within 10% of hand-optimized C size

### Bug debt

- [ ] Every issue tagged `bug` in the tracker resolved or
      explicitly deferred to v1.0 with rationale
- [ ] No `TODO` / `FIXME` / `XXX` comments remain in
      `compiler/` or the safety-cert subset of `stdlib/rods/`

## Success criteria

v0.8.0 ships when:

- [ ] ABI is signed and frozen
- [ ] Safety-cert pilot produces accepted certification artifacts
- [ ] LSP + debug + coverage + profiler all production-ready
- [ ] No open `bug`-tagged issues
- [ ] Migration story for v0.7→v0.8 in CHANGELOG covers the
      ABI freeze in detail
