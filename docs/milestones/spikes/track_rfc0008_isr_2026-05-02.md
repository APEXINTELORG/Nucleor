# Track RFC-0008 ISR Spike — 2026-05-02

Branch: `spike/v06-rfc0008-isr`

Base: `origin/main` v0.6.1 (`983daa4`)

## Scope

First-pass `#[isr]` support for the v0.6 embedded line:

- Source-level recovery of `#[isr]` / `#[isr(...)]` on function declarations.
- Signature validation: ISR handlers must be zero-argument and void-returning (`ISR-001`).
- Deadline composition reject: `#[isr]` + `#[deadline]` fails closed (`ISR-002`).
- Unsupported explicit targets fail closed (`ISR-003`).
- ISR roots inherit no-allocation/no-panic checks by reusing existing RT scanners.
- DCE treats ISR handlers as roots and LLVM IR includes a stable ISR marker:
  `; nucleor.isr target=<target> fn @<name> interrupt_cc`.
