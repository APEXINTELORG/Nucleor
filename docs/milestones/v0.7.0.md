## Static WCET (RFC-0009)

`#[deadline = T]` (RFC-0001 v0.3) currently sets a soft target
checked at runtime via per-iteration cycle counters. v0.7
upgrades this with **static** WCET (worst-case execution time)
analysis via the Heptane open-source toolchain.

| Phase | Item |
|---|---|
| 1 | Heptane bridge: emit annotated assembly that Heptane reads |
| 2 | `nuc wcet` CLI: report WCET per fn |
| 3 | Compile error if `#[deadline = T]` fn's WCET > T |
| 4 | Per-target cost models (Cortex-M3, M4F, M7, RV32IMAC) |
| 5 | Loop-bound annotations: `#[loop_max(N)]` so Heptane has
      enough info to bound iteration counts |

This is the key feature for safety-critical certification work
(IEC 61508, DO-178C, ISO 26262). The cert-mode build profile
(introduced in RFC-0006 v0.5) requires WCET proof for any
`#[deadline]` fn.

## DLPack tensor interchange (RFC-0010)

Zero-copy tensor handoff to / from PyTorch, JAX, NumPy, TVM,
TensorFlow via the DLPack standard. Existing `tensor_nd.nr` and
`tensor_decomp.nr` rods become DLPack-source / DLPack-sink with
no data copy.

| Phase | Item |
|---|---|
| 1 | DLPack header (`dlpack.h`) bundled in runtime |
| 2 | `tensor_to_dlpack()` / `tensor_from_dlpack()` rod helpers |
| 3 | Integration test with PyTorch via `nuc-cxx` (RFC-0011 v0.4) |
| 4 | Stride / device-type / dtype mapping table |
| 5 | Error path for incompatible dtype / device |

Once DLPack lands, Nucleor's full numerical stack (autodiff,
linalg, FFT, ODE) becomes callable from any major ML framework
with zero serialization cost.

## Certified-build profile

`nuc build --profile=cert` enforces a strict superset of safety
guarantees:

- All `#[deadline]` fns have static WCET proven (RFC-0009)
- All contracts (`#[require]`, `#[ensure]`, `#[invariant]`) have
  static proof or explicit `#[unverified]` annotation
- No `#[allow]` for safety-cert error codes (NUM-*, OWN-*, RT-*)
- No `panic!` reachable from `#[no_panic]` paths
- Build manifest hash + LLVM IR hash signed for audit trail
