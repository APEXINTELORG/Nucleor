# v0.2.0 Milestone Tracker

**Target:** 2026-06
**Theme:** Foundation — numerics, Result/Option/match, modules, packages, diagnostics, tests, cross-platform
**Status:** Planning (RFCs locked, build starting)

This is the **canonical sequencing doc** for the v0.2.0 release. Each
RFC has a checklist of milestones; PRs link back here.

## Critical-path summary

```
RFC-0015 (numerics) ─┬─> RFC-0016 (Result/Option/match) ─┬─> RFC-0017 (collections)
                     │                                    │
                     ├─> RFC-0020 (diagnostics, parallel) │
                     │                                    └─> v0.2 RC
                     ├─> RFC-0018 (modules, parallel) ────┘
                     │
                     ├─> RFC-0019 (package mgr resolver, parallel)
                     ├─> RFC-0021 (test framework, parallel)
                     └─> RFC-0022 (cross-platform, parallel)
```

Critical path: RFC-0015 → RFC-0016 → RFC-0017. The other four RFCs
ship in parallel and don't gate the release if late.

## Success criteria

v0.2.0 ships when:
- [ ] All 8 RFCs above implemented to their definition-of-done
- [ ] Verify gate green on Windows + Linux + macOS (Intel + ARM)
- [ ] At least 10 v0.1.x example programs migrate cleanly via
      `nuc fix`
- [ ] CHANGELOG documents all breaking changes + migration story
- [ ] Doc gen (RFC-0029) is at least skeleton (full in v0.4)
- [ ] No Tier-1 regression vs v0.1.8
