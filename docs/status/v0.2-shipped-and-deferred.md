# v0.2 — what shipped, what's deferred

Snapshot 2026-04-23, as of tag `v0.2.76`. Source of truth is
[`docs/milestones/v0.2.0.md`](../milestones/v0.2.0.md) +
[`docs/milestones/v0.4.0.md`](../milestones/v0.4.0.md) +
[`CHANGELOG.md`](../../CHANGELOG.md). This doc is the rolled-up
view across **all 97 releases in the `v0.1.46`→`v0.2.76` chain**
(22 v0.1.x preview releases + 76 v0.2.x releases including the
v0.2.0 RC itself, the v0.2.18–v0.2.30 enrichment chain, the
v0.2.41–v0.2.49 manifest-contract chain, and the v0.2.50–v0.2.76
post-RC hardening / Phase 2 population sub-chain).

### Post-RC sub-chain (v0.2.50–v0.2.76, 27 releases)

All tooling-only — no compiler / runtime / source / test
changes. Self-host LLVM IR fixed point preserved on every
promotion.

- **Helper manifest Phase 2 population (v0.2.73–76)** — 628 of
  676 helpers (92.9%) now carry populated `effects` / `taint` /
  `proof_obligation` fields. Remaining 48 TODO rows are
  intentional v0.4 placeholders. Generator carries 3-level
  resolution chain (`NAME_OVERRIDES` → `PATTERN_OVERRIDES` →
  `CLASS_DEFAULTS`). Schema vocabulary added `"sync"` effect
  tag for synchronization-only primitives.
- **CLI surface gate coverage (v0.2.64–72)** — 16 unique
  user-facing CLI subcommands now under explicit smoke
  coverage in both `verify.sh` and `verify.ps1`. Step total
  grew 158 → 195 (`explain`, `bootstrap`, `check`, `abi`,
  `summary`, `audit`, `query`, `impact`, `policy`, `certify`,
  `translate`, `evidence`, `graph`, `perf`, `bench`, `init`,
  `doc`, `lock`, `test`).
- **Drift gate hardening (v0.2.50–63)** — single source of
  truth for the example list (`tools/examples.list`),
  rust_bridge artifact two-name detection (POSIX
  `libnucleor_rust_bridge.a` + Windows MSVC
  `nucleor_rust_bridge.lib`), and freshness gates on four
  generated artifacts (`helper_manifest.toml`,
  `rod_manifest.toml`, `RELEASES.md`, s1↔tools ABI parity).
- **Compiler bug fix (v0.2.69)** — `nuc test foo.nr` from a
  fresh directory failed because `nucleor_tools_suite.nr`
  wrote the test harness to `target/` without first creating
  the directory. Fixed with a one-line
  `system("mkdir target 2>NUL")` before the
  `file_write_string` call. The `cli_test_smoke` step
  shipped in the same release would have caught this pre-fix.
- **Bash gate clang fallback (v0.2.72 drive-by)** — added
  `C:\Program Files\LLVM\bin\clang.exe` as a Windows
  fallback for the bash `verify.sh` clang resolver, after a
  stale `LLVM_SYS_180_PREFIX` produced ~150 spurious link
  failures. Mirrors the PowerShell gate's behavior.

## What's next

The v0.4 follow-on push picks up from
[`docs/milestones/v0.4.0.md`](../milestones/v0.4.0.md) — every
deferred row above is in there with the v0.2 release where the
foundation work landed, so v0.4 implementation picks up at "wire
it in" rather than "design it".

Highest-leverage v0.4 starting points (in order):

1. **Range patterns in match (RFC-0023 §3.1)** — `match x { 1..=5
   => ..., _ => ... }`. Drives MATCH-007 firing. Smallish parser
   change, large user-visible win.
2. **Generic enums (RFC-0024)** — unblocks compiler-integrated
   `Result<T,E>` / `Option<T>` (RFC-0016 phase 4) and the rest of
   the typecker chain.
3. **Iterator trait + adapter chain (RFC-0024)** — unlocks
   ergonomic stdlib idioms.
4. **Module resolver with `pub` enforcement (RFC-0018 phase 2)** —
   needs the symbol-table refactor; paired with generic enums.
5. **Stdlib audit + strict-mode flip (RFC-0015 phase 3+5+7)** —
   one coordinated push using `nuc fix --numeric` as the driver.
