## Summary

R3 ships the RFC-0062 G-10 effect annotations framework: `#[effect(...)]`
declaration syntax, `#[allow_effect(...)]` opt-out syntax, an effect-row
checker pass that runs after the existing `enforce_requires_direct_calls`,
and three diagnostic codes registered in `is_error_code` immediately after
R2's `INIT-G11-READ-BEFORE-INIT`:

  - `EFFECT-G10-UNDECLARED`
  - `EFFECT-G10-MISSING-ALLOW`
  - `EFFECT-G10-WRONG-ROW`

Initial vocabulary (closed set): `frees`, `borrows_mut`, `may_return_null`,
`direct_ffi`. Leaf inference today only fires on `vec_free` / `hashmap_free`
/ `str_free` → `frees`; R4 (G-5 + G-7 + G-9) extends the leaf table for
`direct_ffi`, `may_return_null`, `borrows_mut`.

## Inference design

Conservative one-hop. Two passes inside `g10_compute_body_effects`:

  - **Pass A — leaf builtins.** Hardcoded table:
    `vec_free` / `hashmap_free` / `str_free` → `frees`.
  - **Pass B — call propagation.** A call to a same-source fn whose
    `#[effect(...)]` row declares effect E contributes E to the
    caller's produced set.

Cheap gate: textual `str_contains` for the attribute syntax. Real-attr
gate: `g10_collect_attr_pairs` (which skips `// ...` line comments and
`"..."` string literals). If both decls and allows pair-lists are
empty, the function returns the diags Vec unchanged. This double gate
keeps the existing 1490-step verify budget intact.

## Adopter ergonomics surfaced during fixture authoring

The G-1 default-flip auto-drop pass interacts with `frees` effect
fixtures: a fn that calls `release(v)` (where `release` does
`vec_free(v)`) will, post-default-flip, also try to auto-drop `v` at
the end of its scope — second free, segfault. The kind-7 transitive-
handoff recognition (DFLIP-PATCH @ 8cdee78d) handles the canonical
case where the wrapper layer's fn returns a handoff, but here the
caller doesn't return — `release(v)` is a fire-and-forget pass-by-
move. The framework-level fix is the same as the rest of the
`#[manual_drop]` corpus: annotate the caller. All three positive
fixtures use `#[manual_drop]` on every fn that touches the freed
binding, which is the canonical adopter pattern in the existing
`tests/err/err_own_g4_*` corpus.
