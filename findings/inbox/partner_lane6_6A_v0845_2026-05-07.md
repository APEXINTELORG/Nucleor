## Diagnostic chosen + rule chosen

- Diagnostic: `TYP-026`.
- Constant rule: `as char` constants must be Unicode scalar values: `0..0x10FFFF` excluding `0xD800..0xDFFF`.
- Non-constant rule: only the exact variable binding may be cast, and only inside a then-branch whose condition proves both:
  - lower bound: `v >= 0`, `0 <= v`, `v > -1`, or `-1 < v`;
  - upper bound below surrogate start: `v < 0xD800`, `v <= 0xD7FF`, or equivalent reversed ordering.
- Chosen proof form is deliberately narrow and fail-closed. It accepts the requested `v >= 0 && v < 0xD800` style and rejects unguarded dynamic values.
