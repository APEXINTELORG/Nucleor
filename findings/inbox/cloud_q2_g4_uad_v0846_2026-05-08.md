## Bug shape (the gap this closes)

Per RFC-0062 §3.3 G-4: `vec_free(v); ...; v.push(7);` — adopter manually
frees, then uses. Today the second use silently crashes at runtime.

Why OWN-001 doesn't catch it: `is_copy_type` (line ~19431) returns 1 for
`Vec`, `HashMap`, and `StringBuilder`. The i64-everywhere ABI represents
these as i64 handles, so the move-state tracker treats them as Copy —
passing one positionally to `vec_free` does NOT mark the slot as moved.
Subsequent reads pass through. The Phase 2a OWN-012 textual count
(integrator-promoted to warning at Phase A) surfaces the call sites but
does not enforce.

Phase 2b spec: "Walk IR per-fn. After every `drop` or auto-drop insertion
point, mark the value's slot as dead. Any subsequent use of that slot in
the same CFG path → diagnostic OWN-G4-USE-AFTER-DROP." Phase 4 promotes
to hard error.

## Patch shape

Three additive edits to `compiler/nucleor_s1_compiler.nr`:

1. **Diagnostic registration** (line ~11113). Add
   `OWN-G4-USE-AFTER-DROP` to `is_error_code`. Phase 4 promotion via
   `own_diag` (always emits at error severity).

2. **Freed-flag check in kind-3 read** (`check_expr`, line ~19461,
   *before* the existing OWN-001 use-of-moved branch). Read
   `__g4_freed_<name>` raw flag; if set, emit OWN-G4-USE-AFTER-DROP
   citing the original free-helper name (cached as
   `__g4_freed_by_<name>`). Returns immediately so OWN-001 doesn't
   double-fire on the same node.

3. **Freed-flag set in kind-7 free dispatch** (`check_expr`, line
   ~19533, alongside the existing arena_destroy / OWN-003 / move-state
   branches). When `callee_name` is `vec_free` / `hashmap_free` /
   `str_free` and the arg is a kind-3 var-ref, set
   `__g4_freed_<aname> = 1` and `__g4_freed_by_<aname> = callee_name`.

The flag is per-fn (lives on the `own` env that's reset per `check_fn`
invocation), so cross-fn aliasing is not in scope (per the brief: "in
the same CFG path"). Double-free is caught for free: the second
`vec_free(v)` call's arg-walk reads `v` while the freed flag is set, so
OWN-G4-USE-AFTER-DROP fires *before* the second free's flag-set runs.

Cooperation with G-1 default-flip auto-drop: auto-drop bindings have
their cleanup inserted at scope exit by the lowering pass; the freed
flag here only fires on **explicit** `vec_free` / `hashmap_free` /
`str_free` calls. Adopter pattern of `vec_free(v); /* return */` stays
clean (no read after free → no diag). Adopter pattern of
`vec_free(v); some_use(v);` fires.

Independent of move-state OWN-001:
- `is_copy_type("Vec<i64>")` returns 1; OWN-001 won't trip on Vec
  reads after vec_free even with the existing tracker. The Phase 2b
  freed flag is a parallel mechanism specifically for this gap.
- For non-copy types like `Box<T>`, OWN-001 already catches misuse via
  state==2; my freed flag adds an additional layer for the explicit
  free helpers (which is the documented adopter idiom for Vec/HashMap).

## Honesty

- The freed-flag mechanism is a **per-name** flag on the `own` env;
  it does NOT track aliases. Adopters who write `let w = v;
  vec_free(v); use(w);` get a UAF that this Phase 2b doesn't catch.
  Alias tracking is a Phase 3 ramp item per the plan; not in this Q
  per the brief's "Phase 2b + Phase 3 + Phase 4 in one ship" framing
  (where Phase 3 here = no behavior change, Phase 4 = error severity).
- The integrator's Phase A promoted OWN-012 textual audit to warning
  level; my Phase 2b adds a structural check at error severity for a
  different kind of misuse (use-after-explicit-free, vs. OWN-012's
  arena-destroy-with-live-ref). The two diagnostics co-exist and
  target different error classes — confirmed both still fire on their
  respective fixtures during full verify.
- Cooperation with G-1's default-flip auto-drop: the freed flag does
  not fire on auto-drop insertions because those happen at lowering
  time after `check_expr` runs. So an `#[auto_drop]` binding used
  legitimately, then auto-cleaned at scope exit, sees zero diags.
  Verified by stage-2 self-rebuild — the seed compiler's source uses
  `#[manual_drop]` opt-out for ~30 fns and auto-drop default for the
  rest; both modes compile clean post-Q2.
